# E-Ticaret REST API (Backend Staj Projesi)

Bu proje, Node.js, Express ve PostgreSQL kullanılarak geliştirilmiş modüler bir E-Ticaret backend uygulamasıdır. Staj programı kapsamında gün gün üzerine yeni özellikler eklenerek geliştirilmektedir.

## 🚀 Geliştirilen Özellikler
- **Kimlik Doğrulama:** Bcrypt ve JWT ile güvenli kayıt/giriş sistemi.
- **Ürün Yönetimi:** Ürün ekleme, silme, güncelleme ve listeleme (CRUD).
- **Sepet ve Sipariş:** Kullanıcıya özel sepet yönetimi ve sepeti siparişe dönüştürme.
- **Kullanıcı Profili:** Hesap bilgileri güncelleme ve sipariş geçmişi görüntüleme.

## 🛠️ Kullanılan Teknolojiler
- Node.js & Express.js
- PostgreSQL (Neon.tech)
- JsonWebToken (JWT) & Bcrypt
